The basic problem

We want inference for the conditional relationship

\[p(Y\mid X,\theta)\]

but both Y and X may be partly unobserved.

BAYESIAN MISSING DATA

Observed and missing components

\[Y=(Y_{\mathrm{obs}},Y_{\mathrm{mis}})\]
\[X=(X_{\mathrm{obs}},X_{\mathrm{mis}})\]

Let R encode the observed/missing pattern (1 = observed).

BAYESIAN MISSING DATA

Three probability models

\[\underbrace{p(Y\mid X,\theta)}_{\text{outcome}}\quad \underbrace{p(X\mid\phi)}_{\text{covariates}}\]
\[\underbrace{p(R\mid Y,X,\psi)}_{\text{missingness}}\]
BAYESIAN MISSING DATA

Complete-data factorization

\[p(Y,X,R,\theta,\phi,\psi)=p(R\mid Y,X,\psi)\,p(Y\mid X,\theta)\,p(X\mid\phi)\,p(\theta,\phi,\psi)\]

A selection-model factorization; prior independence is optional.

BAYESIAN MISSING DATA

Observed-data likelihood

\[L(\theta,\phi,\psi)=\iint p(R\mid Y,X,\psi)\,p(Y\mid X,\theta)\,p(X\mid\phi)\,dY_{\mathrm{mis}}\,dX_{\mathrm{mis}}\]

Integrate only the missing components; sum for discrete variables.

BAYESIAN MISSING DATA

MCAR

\[p(R\mid Y,X,\psi)=p(R\mid\psi)\]

Missingness is independent of observed and unobserved values.

BAYESIAN MISSING DATA

MAR

\[p(R\mid Y,X,\psi)=p(R\mid Y_{\mathrm{obs}},X_{\mathrm{obs}},\psi)\]

For each realized pattern, the probability of that pattern does not vary with missing values.

BAYESIAN MISSING DATA

MNAR

\[p(R\mid Y,X,\psi)\text{ depends on }(Y_{\mathrm{mis}},X_{\mathrm{mis}})\]

Missingness remains dependent on unobserved values after conditioning on what is observed.

BAYESIAN MISSING DATA

Ignorability

Under MAR, parameter distinctness, and an appropriate factorized prior:

\[p(\theta,\phi\mid D_{\mathrm{obs}},R)\propto p(\theta,\phi)\iint p(Y\mid X,\theta)p(X\mid\phi)\,dY_{\mathrm{mis}}dX_{\mathrm{mis}}\]

Ignoring the missingness model does not mean ignoring missing predictors.

\[X_i\mid\phi\sim N(\mu_x,\tau^2)\]
BAYESIAN MISSING DATA

Missing outcome, observed predictor

\[\int p(y_i\mid x_i,\theta)\,dy_i=1\]

Under independent sampling and ignorability, this subject adds no direct likelihood information about the regression parameters.

BAYESIAN MISSING DATA

Observed outcome, missing predictor

\[p(y_i\mid\theta,\phi)=\int p(y_i\mid x_i,\theta)p(x_i\mid\phi)\,dx_i\]

A model for the predictor distribution is now needed.

BAYESIAN MISSING DATA

Gaussian marginalization

\[Y_i\mid\theta,\phi\sim N(\alpha+\beta\mu_x,\;\sigma^2+\beta^2\tau^2)\]

Even with missing X, the observed Y can inform the regression parameters.

Data augmentation

\[p(\theta,\phi,Y_{\mathrm{mis}},X_{\mathrm{mis}}\mid D_{\mathrm{obs}})\propto p(Y\mid X,\theta)p(X\mid\phi)p(\theta,\phi)\]

Sample missing values and parameters jointly, rather than evaluating the integral directly.

BAYESIAN MISSING DATA

Missing predictors use observed outcomes

\[p(x_i\mid y_i,\theta,\phi)\propto p(y_i\mid x_i,\theta)p(x_i\mid\phi)\]

Imputation of predictors should generally condition on the outcome.

BAYESIAN MISSING DATA

Gaussian conditional imputation

\[X_i\mid y_i,\theta,\phi\sim N(m_i,v_i)\]
\[v_i=\left(\tau^{-2}+\beta^2/\sigma^2\right)^{-1}\]
\[m_i=v_i\left(\mu_x/\tau^2+\beta(y_i-\alpha)/\sigma^2\right)\]

Prediction with a missing predictor

\[p(y_*\mid D_{\mathrm{obs}})=\iint p(y_*\mid x_*,\theta)p(x_*\mid\phi)p(\theta,\phi\mid D_{\mathrm{obs}})\,dx_*d\theta d\phi\]

Integrate over both parameter and predictor uncertainty.

Posterior predictive imputations

BAYESIAN MISSING DATA

Rubin’s rules: point estimate

\[\bar Q=\frac{1}{M}\sum_{m=1}^M\hat Q_m\]

Each completed dataset produces an estimate \(\hat Q_m\) and estimated variance \(U_m\).

BAYESIAN MISSING DATA

Rubin’s rules: uncertainty

\[\bar U=\frac1M\sum_{m=1}^M U_m\]
\[B=\frac1{M-1}\sum_{m=1}^M(\hat Q_m-\bar Q)^2\]
\[\boxed{T=\bar U+(1+M^{-1})B}\]
BAYESIAN MISSING DATA

Why two variance components?

\[\operatorname{Var}(\theta\mid D_{\mathrm{obs}})=E[\operatorname{Var}(\theta\mid D)] +\operatorname{Var}[E(\theta\mid D)]\]

Within-imputation uncertainty + between-imputation uncertainty. Expectations are over missing data given observed data.

MICE / chained equations

\[p(Z_1\mid Z_{-1}),\;p(Z_2\mid Z_{-2}),\;\ldots,\;p(Z_k\mid Z_{-k})\]

Cycle through variable-specific conditional imputation models. These conditionals need not define a compatible joint distribution.

Congeniality matters

\[E(Y\mid X)=\alpha+\beta_1X_1+\beta_2X_2+\beta_3X_1X_2\]

An imputation model that omits interactions or nonlinearities can distort the substantive regression analysis.

BAYESIAN MISSING DATA

Why sensitivity analysis?

MAR is usually not testable from observed data alone.

Vary assumptions about missing values and assess how conclusions change.

BAYESIAN MISSING DATA

What is identified?

\[p(D_{\mathrm{obs}},R)=\int p(D_{\mathrm{obs}},D_{\mathrm{mis}},R)\,dD_{\mathrm{mis}}\]

Different MNAR models may induce the same observed-data distribution yet imply different missing-data distributions.

BAYESIAN MISSING DATA

Pattern-mixture sensitivity

\[p(Y,X\mid R)=p(Y,X\mid R;\delta)\]

Specify how the distribution of missing values differs across missingness patterns. \(\delta\) indexes departures from MAR.

BAYESIAN MISSING DATA

Delta adjustment for missing Y

\[Y_{\mathrm{mis}}^{(m,\delta)}=Y_{\mathrm{mis}}^{(m,\mathrm{MAR})}+\delta\]

For continuous outcomes, shift MAR imputations by a scientifically plausible amount. \(\delta=0\) is the reference scenario.

BAYESIAN MISSING DATA

Sensitivity for missing X

\[X_{\mathrm{mis}}^{(m,\delta_x)}=X_{\mathrm{mis}}^{(m,\mathrm{MAR})}+\delta_x\]

Refit \(Y\mid X\) across a grid of \(\delta_x\). For binary predictors, shift an appropriate latent scale or log odds instead.

BAYESIAN MISSING DATA

Selection-model sensitivity

\[\operatorname{logit}P(R_{Yi}=1\mid Y_i,X_i)=a+b^\top X_i+\gamma Y_i\]

The parameter \(\gamma\) describes dependence on potentially unobserved outcomes. Fix or vary \(\gamma\) over plausible values.

BAYESIAN MISSING DATA

Joint missingness in Y and X

\[p(R_Y,R_X\mid Y,X,\psi)\]

Sensitivity parameters may govern dependence on missing outcomes, missing predictors, and their interaction.

One-at-a-time analyses are useful, but joint scenarios may be necessary.

Sensitivity is not a prior-free solution

\[p(\theta,\delta\mid D_{\mathrm{obs}})\propto p(D_{\mathrm{obs}}\mid\theta,\delta)p(\theta,\delta)\]

If \(\delta\) is weakly identified, its posterior can be driven by its prior. Report assumptions transparently.

A practical sensitivity workflow

1Fit a defensible MAR reference model
2Choose interpretable MNAR parameters
3Repeat MI / posterior inference over a grid
4Plot effects and uncertainty; locate tipping points
BAYESIAN MISSING DATA

What to report

  • Missingness patterns and observed-data diagnostics
  • Imputation / covariate models and substantive model
  • Sensitivity parameter definitions and plausible ranges
  • Effect estimates and uncertainty across scenarios
  • Which conclusions are robust—and which are not
BAYESIAN MISSING DATA

Takeaways

  • Missing X usually requires modeling its distribution
  • Under MAR, the missingness mechanism can be ignorable—not the missing data
  • MI propagates uncertainty through repeated completed-data analyses
  • MNAR sensitivity analysis probes assumptions the observed data cannot settle
