# Bayesian Missing Data — Reveal.js slides

A minimalist 23-slide presentation on Bayesian missing data in regression when both outcomes and predictors may be missing.

## Preview locally

Open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000.

## Publish with GitHub Pages

1. Create a public GitHub repository (or use an existing repository).
2. Upload `index.html` to the repository root and commit it.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
4. Visit `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/` once Pages publishes.

For a repository named `YOUR-USERNAME.github.io`, the site URL is `https://YOUR-USERNAME.github.io/`.

## Controls

Arrow keys or space to advance; `Esc` for overview; `S` for speaker view. Add `?print-pdf` to the URL and use your browser's print-to-PDF function for a PDF handout.

## Dependencies

Reveal.js and MathJax are loaded via public CDN. The slides require an internet connection for those libraries, but no build tooling or package installation.
